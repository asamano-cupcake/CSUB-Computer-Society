The CSUB IEEE Computer Society Club developed a fully working spider, developing the design
of necessary components for the functionality and portability in mind, as well as limitations.

The CSUB IEEE Computer Society club is a chartered CSUB club organization. We are not 
affiliated with the IEEE Computer Society organization currently, but we are in the 
development of submitting a pettition and hopefully gaining an IEEE Computer Society 
Student Branch Chapter at CSUB. 

The purpose of this project is for students to learn how to devlop code with Arduino IDE,
and enjoy the entire engineering process from start to finsih. 

The way the events will be hosted is first a software event, to download Arduino IDE, 
explain the purpose of the code, what libraries are necessary, how to control servos with
the PCA9685 servo driver board, and how to develop your own scripts.

Installation:
	For a windows laptop, you can download the arduino ide from their downloads page.
	For Mac OS, you can also download the arduino ide from their downloads page.
	For linux, it's a little more complex.
		What worked for me was to download the Arduino IDE imager on their webpage,
		but run it through the terminal to jumpstart the event.

		If anyone knows a better way to do this, please let us know.

How the Directory Works:
	In this directory, there is a scripts folder and a models folder. 
	The scripts folder contains all the troubleshooting and testing different libraries.
	It includes different setups for the spider as well, with the main inspiration from
	AliExpress
	In the Models directory, it shows the cad files that were made for the components
	and spider build. It also contains a json file that includes all of the dimensions
	of the pieces, and the electrical parts themselves. 
	In the electronics portion, it is a directory of explaining why we chose the components
	that we did, what equations we used, and the final schematic.
	The BUILD.md includes the listed instruction for building the final spider

We highly encourage students to truly read all the documents and ask themselves questions 
on how they can improve the system. Ultimately, this spider is very introductory, and the 
calculations were done with the knowledge that we know. If there are ways that it can be improve,
or any miscalculated procedure, we encourage you to reach out so that we can all improve.

# CSUB-Computer-Society
This repository hosts projects created by the developing CSUB IEEE Computer Society student club. We are currently seeking recognition as an official IEEE Computer Society Student Branch Chapter. Until chartered, these projects are independently created and do not represent or imply endorsement by IEEE or the IEEE Computer Society.

# Outline of Repository
Anytime that the CSUB IEEE Computer Society club hosts an interactive event, we will post the documents and supporting files to this gihtub account. Currently, it is run through the president's account, and once a club email is formed, it will be switched over to that account. The projects will be on their own folders, and we recommend students to look over the files and informations and make their own deductions or innovations.

# Goal
The primary goal we hope to achieve is for students to use the knowledge learned through the club and apply them to their own project. Ultimately if any of the information is false, or a calculation or approach is incorrect, please don't feel afraid to let us know. We want to ensure that every project is carefully planned and researched so that we don't give out false information or misleading deductions. Please let us know if anything can be improved in any way.
